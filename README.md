# IIG Quick Switch

Маленькое отдельное расширение-виджет для **SillyImages** (и опционально **ExtBlocks**).
Не патчит и не заменяет основные расширения — просто читает и пишет те же настройки
(`extensionSettings.inline_image_gen`, `extensionSettings.ExtBlocks`), что и они, и не
требует их как формальную зависимость на уровне manifest (просто должны быть установлены рядом).

## Что делает

Плавающая кнопка (палитра 🎨) поверх интерфейса. Тап — открывает маленькую панель:

- **Стиль** — чипы с только выбранными стилями из настроек SillyImages («Стили») — по умолчанию
  список пуст: жми на шестерёнку ⚙ рядом с заголовком, отметь нужные в списке (или «Отметить
  все» одной кнопкой) — они появятся как чипы. «Без стиля» показывается всегда, без отметки.
  Тап по чипу мгновенно ставит стиль активным и закрывает панель.
- **Пресет подключения** — та же «Пресеты подключения» под «Настройки API» в SillyImages
  (тип API, эндпоинт, ключ, модель и связанные параметры генерации). Выбор пресета в
  выпадающем списке применяет его сразу, без открытия большой панели.
- **Connection Profile (ExtBlocks)** — быстрое переключение профиля подключения из
  Connection Manager SillyTavern для текущего активного API Preset (Big/Medium/Small)
  в ExtBlocks. Как и с блоками — показывает только отмеченные профили (шестерёнка ⚙),
  переключение идёт через родной `<select>` ExtBlocks.
- **Пресеты блоков (ExtBlocks)** — быстрое вкл/выкл отдельных блоков из текущего активного
  набора ExtBlocks (тех, что видны в списке «Preset blocks:» в его настройках — например,
  `ilustr`, `sims`, `diary` и т.д.). Специально показывает **не все блоки сразу**, а только
  те, что ты сам отметил: жми на шестерёнку ⚙ рядом с заголовком секции — откроется список
  всех блоков текущего набора с чекбоксами, отметь нужные — и они появятся как чипы. Тап по
  чипу включает/выключает именно этот блок (чип светится, если блок сейчас включён); панель
  при этом не закрывается, чтобы удобно было переключить сразу несколько блоков подряд.
  Список отмеченных хранится в собственных настройках виджета и не трогает сам ExtBlocks.
  Переключение выполняется через родной чекбокс блока в его настройках (с событием `change`),
  поэтому честно отрабатывает вся его внутренняя логика.

Если панель настроек SillyImages в этот момент тоже открыта на экране — виджет сразу
подсвечивает в ней выбранный стиль/пресет, чтобы обе не расходились визуально.

Кнопку можно перетащить в удобное место (например, повыше от нижней панели на телефоне) —
позиция запоминается в этом браузере.

Если стилей, профилей или пресетов блоков ещё нет (или расширение ExtBlocks не установлено) —
панель покажет короткую подсказку вместо соответствующей секции.

## Установка

1. Скопируй папку `iig-quickswitch` в:
   ```
   SillyTavern/public/scripts/extensions/third-party/iig-quickswitch/
   ```
2. Перезагрузи SillyTavern (или обнови страницу, если ST уже запущен и подхватывает
   новые расширения без рестарта — зависит от версии).
3. Расширение должно быть включено в списке расширений (обычно включено по умолчанию
   после установки).

## Если что-то не устраивает

- **Иконка кнопки**: в `index.js` в самом начале — константа `FAB_ICON_CLASS`.
  Сейчас `'fa-solid fa-palette'`. Спокойные альтернативы: `fa-solid fa-wand-magic-sparkles`,
  `fa-solid fa-swatchbook`, `fa-solid fa-brush`, `fa-solid fa-sliders`.
- **Размер/прозрачность кнопки**: в `style.css`, класс `.iigqs-fab` (свойства `width`/`height`,
  `opacity`).
- **Стартовая позиция кнопки** (пока не подвигаешь её сам): в `index.js`, функция
  `injectFab()`, переменная `pos` (`right`/`top` в пикселях).
