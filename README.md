# IIG Quick Switch

Маленькое отдельное расширение-виджет. Не патчит и не заменяет основные расширения —
просто читает и пишет те же настройки, что и они.

## Что делает

Плавающая кнопка (лапка 🐾) поверх интерфейса. Тап — открывает маленькую панель:

- **Стиль** — чипы с только выбранными стилями («Стили» в настройках) — по умолчанию
  список пуст: жми на шестерёнку ⚙ рядом с заголовком, отметь нужные в списке (или
  «Отметить все» одной кнопкой) — они появятся как чипы. «Без стиля» показывается
  всегда, без отметки. Тап по чипу мгновенно ставит стиль активным и закрывает панель.
- **Профиль подключения** — тип API, эндпоинт, ключ, модель и связанные параметры
  генерации. Выбор профиля в выпадающем списке применяет его сразу, без открытия
  большой панели настроек.
- **Connection Profile (ExtBlocks)** — быстрое переключение профиля подключения из
  Connection Manager SillyTavern для текущего активного API Preset (Big/Medium/Small)
  в ExtBlocks. Показывает только отмеченные профили (шестерёнка ⚙), переключение идёт
  через родной `<select>` ExtBlocks.
- **Пресеты блоков (ExtBlocks)** — быстрое вкл/выкл отдельных блоков из текущего
  активного набора ExtBlocks. Специально показывает не все блоки сразу, а только те,
  что ты сам отметил: жми на шестерёнку ⚙ рядом с заголовком секции — откроется список
  всех блоков текущего набора с чекбоксами, отметь нужные — и они появятся как чипы.
  Тап по чипу включает/выключает именно этот блок (чип светится, если блок сейчас
  включён); панель при этом не закрывается, чтобы удобно было переключить сразу
  несколько блоков подряд. Переключение выполняется через родной чекбокс блока в его
  настройках (с событием `change`), поэтому честно отрабатывает вся его внутренняя
  логика.

Если родная панель настроек в этот момент тоже открыта на экране — виджет сразу
подсвечивает в ней выбранный стиль/профиль, чтобы обе не расходились визуально.

Кнопку можно перетащить в удобное место — позиция запоминается в этом браузере и не улетает за край экрана даже
если раньше её двигали на устройстве с другим размером экрана.

Иконка кнопки и акцентные цвета в панели подхватываются из текущей темы SillyTavern (в теме влияет именно цвет курсива и текста в кавычках) — меняешь тему в настройках, виджет перекрашивается вместе с ней.

Если стилей, профилей или пресетов блоков ещё нет (или расширение ExtBlocks не
установлено) — панель покажет короткую подсказку вместо соответствующей секции.

## Объединение полей подключения

`CONNECTION_FIELDS` в `index.js` — объединение полей подключения из двух исходных
форков этого виджета: xai*, a1111*, `naisteraCharacterDescriptionsMode`,
`naisteraPolling`/`naisteraPollIntervalMs`/`naisteraPollTimeoutMs` — из одного,
electronhub*/novelai*/override* — из другого. Если каких-то из этих провайдеров
у тебя сейчас нет — соответствующие поля просто не используются, ничего не ломают.

## Установка

1. Скопируй папку `iig-quickswitch` в:
   ```
   SillyTavern/public/scripts/extensions/third-party/iig-quickswitch/
   ```
2. Перезагрузи SillyTavern (или обнови страницу, если ST уже запущен и подхватывает
   новые расширения без рестарта — зависит от версии).
3. Расширение должно быть включено в списке расширений (обычно включено по умолчанию
   после установки).

## Если что-то не устраивает

- **Иконка кнопки**: в `index.js` в самом начале — константа `FAB_ICON_CLASS`.
- **Размер/прозрачность кнопки**: в `style.css`, класс `.iigqs-fab` (свойства
  `width`/`height`, `opacity`).
- **Стартовая позиция кнопки** (пока не подвигаешь её сам): в `index.js`, функция
  `injectFab()`, переменная `pos` (`right`/`top` в пикселях).
